# Autosalon Manager

Консольное приложение на Java для управления автосалоном.

## Сущности
- Автомобиль (Car)
- Клиент (Client)
- Заказ (Order)

## Возможности
- поиск автомобилей по марке;
- фильтрация клиентов по бюджету.

## Сборка и запуск
```
javac -d out src/autosalon/*.java
java -cp out autosalon.Main
```
